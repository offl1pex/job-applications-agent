Список в Python — это упорядоченная изменяемая коллекция элементов.
Элементы пишутся в квадратных скобках: [1, 2, 3].
Частые операции: append (добавить в конец), pop (удалить), len (длина).
Индексация с нуля: первый элемент lst[0].

Словарь (dict) хранит пары ключ–значение: {"name": "Anna", "age": 25}.
Доступ по ключу: d["name"]. Метод get позволяет избежать ошибки, если ключа нет.
Ключи должны быть неизменяемыми (строка, число, кортеж).

Для чтения файлов удобен with open(...) as f — файл закроется сам.
JSON в Python: json.load читает из файла, json.dump записывает.
