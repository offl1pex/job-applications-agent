AI-агент — это программа, где языковая модель может вызывать инструменты (tools).
Обычный чат только отвечает текстом. Агент: подумал → вызвал функцию → получил результат → ответил.

Типичный цикл:
1. Пользователь пишет сообщение.
2. Модель либо отвечает, либо возвращает tool_calls.
3. Программа выполняет функцию и добавляет результат с role "tool".
4. Модель формирует итоговый ответ человеку.

Историю хранят в списке messages: system, user, assistant, tool.
Статусы откликов на вакансии в учебном проекте: applied, interview, offer, rejected, ghosted.
