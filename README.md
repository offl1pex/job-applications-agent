# Job Applications Agent

Консольный AI-агент для учёта откликов на вакансии.

Модель сама выбирает нужный инструмент: добавить отклик, показать список, сменить статус, посмотреть статистику или напомнить о «зависших» заявках.

## Возможности

- Добавление отклика (компания, должность, ссылка, заметка)
- Список откликов (всех или по статусу)
- Смена статуса: `applied` → `interview` → `offer` / `rejected` / `ghosted`
- Статистика по статусам
- Follow-up: отклики без движения N дней (по умолчанию 7)
- История диалога в `chat.json`
- Команды `сброс` и `выход`

## Стек

- Python 3
- OpenAI API (function calling / tools)
- JSON для хранения откликов и истории
- python-dotenv для API-ключа
